# Anshul Jain — portfolio

Source for [intelligentape.online](https://intelligentape.online).

The whole site is one static file, `index.html`: no build step and no dependencies apart from Google Fonts. To deploy, serve the repository root as a static site (for example with Cloudflare Pages, build command empty, output directory `/`).

To preview locally, open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
