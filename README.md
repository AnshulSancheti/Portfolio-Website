# Davies Portfolio Clone

A from-scratch React/Vite recreation of the Davies one-page Framer portfolio template, based on the published reference at `https://davies.framer.website/`.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
npm run preview
```

## Included

- Responsive desktop, tablet, and mobile layouts
- Original reference media stored locally in `public/assets`
- Scroll-linked hero, project, service, awards, light-field, grid, and footer parallax
- Hero video, continuous marquees, sticky work cards, and stacked service reveals
- Staggered entrances, animated project links, and a pointer-tracked process spotlight
- Layered award collage with independent scroll movement
- Full-screen navigation, product and testimonial controls
- Animated counters and pricing period toggle
- FAQ accordion and validated contact form UI
- Reduced-motion support

The contact form currently provides an in-page success state. Connect its submit handler to the preferred email or form backend before publishing.
